# LanceNest auth email templates

Paste each file into **Supabase → Authentication → Emails → Templates** (use the "Source"/HTML view),
and set the subject shown below. They match the branded emails LanceNest sends for approvals.

| Template in Supabase | File | Subject |
|---|---|---|
| Confirm signup | confirm-signup.html | Confirm your LanceNest account |
| Reset password | reset-password.html | Reset your LanceNest password |
| Change email address | change-email.html | Confirm your new email address |
| Magic link | magic-link.html | Your LanceNest sign-in link |
